What's in every template

These are the standards I hold every file to before it goes on sale. No exceptions, no rushed releases.

  • Clean, considered layouts

    Every screen is built against a real grid and tested against current design conventions before it's published — not assembled from leftover sections.

  • Retina-ready on every screen

    Layouts are tuned for desktop, tablet, and phone breakpoints individually, and every graphic exports crisp on high-density displays.

  • Set up for easy customising

    Colour, type, and components are wired to global styles, so changing a brand colour or a font once updates it across the entire site.

  • Built to be found

    Semantic markup, descriptive alt text, and clean heading structure throughout, so search engines can read your site as well as your visitors can.

  • Fast by default

    Lightweight assets and minimal dependencies keep load times low, so every template starts from a strong Lighthouse score rather than fighting for one.

  • Direct, one-to-one support

    If something isn't working the way you expect, you email me — not a ticket queue. I answer support requests myself, usually the same day.
